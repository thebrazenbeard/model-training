## One task-scoped cognitive capability exchange

Canonical literal and conversation/message locator -> TaskExecutionLedger TASK_OPENED/source digest/expected head -> current scoped source retrieval -> externally attested InitiativeKernel PROPOSE/ABSTAIN -> advisory reasoning/model-route eligibility -> only host-verified provider with loaded artifact/process/session/nonce -> Pre-Active DONE+COMPLETED+one selected route+verified response bytes -> optional Cricket critique -> Mono task CAS/cold recovery -> independent separately authorized memory PROPOSAL.

Machine-readable proposal: docs/contracts/TRAINING_COGNITIVE_CAPABILITY_INTERFACE_V1.json. This is a contract description and test input, not an installed request dispatcher or verifier.

Canonical task/text: open_message accepts exact bounded nontrimmed input and untrusted opaque conversation/message locators. Same locator and bytes replay the identical task; substituted text rejects. Source digest and TASK_OPENED prove accepted bytes, NOT user authentication, semantics, fact or intent.

Retrieval: scope/referent/proposition and provenance are preserved. Task head/source digest and source-currentness must be checked. The existing Training read-only predecessor utility may retrieve an actual same-conversation accepted historical UI input; it does NOT attest historical truth or the correctness of a caller-projected referent. If absent, HOLD. Never infer a legitimate predecessor from a self-declared correction.

Initiative: existing Mono vera_runtime.protocol.initiative_kernel.InitiativeKernel requires injected trusted verifier input even to select a candidate. Selected proposal never equals user consent, authority, model dispatch, or protected action. Volition and MESO appraisal do not replace it.

Route and provider: existing PORTAL/Mono route assessment is NO_PROTECTED_EFFECT advisory only. Provider must be selected by an authorized host-owned verifier binding task ID/accepted journal head/source digest, provider identity/current revocation, model ID, actual loaded artifact and manifest digests, serving host ID/generation, PID/session/endpoint, receiver-generated nonce with one-time consumption, actual route selection and causal request/response digests. No self-reported ADMITTED flag, signed-looking string, GGUF file, HTTP liveness, critique or policy score suffices.

Result: Pre-Active durable selected-store evidence requires matching task source, exactly one selected route, DONE event, COMPLETED run, actual final text/sha. Mono CAS commits only after independent source-currentness/transport/result readback; ambiguous outcome is UNKNOWN_NO_REDISPATCH using original request identity. Synthetic fixture completion or operational CogLedger COMPLETED cannot become canonical task completion. Memory is a separate proposal to vera_memory with source/scope/privacy, never automatic write/training.
